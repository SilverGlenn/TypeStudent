# Anti-Slop Writing & Documentation Standard

Enforces high-signal, evidence-based, concise technical writing and removes AI-generated filler ("slop").

## Core Principles

1. **Be Direct and Concrete**: State what the program does without promotional cheerleading or meta-commentary.
2. **Cut Banned Buzzwords & AI Tells**:
   - Never use: *delve, dive into, tapestry, plethora, seamlessly, cutting-edge, revolutionize, empower, elevate, unleash, testaments, beacon, crucial, pivotal, nestled, in conclusion, furthermore, moreover, it's worth noting that*.
3. **Avoid Emoji Clutter**: Restrict emojis to functional iconography or eliminate them where plain text is cleaner.
4. **No Throat-Clearing**: Remove introductory fluff like "In this section we will explore..." or "Welcome to the ultimate guide...". Jump straight to instructions or facts.
5. **Accurate Evidence**: Describe features with exact keybindings, file locations, data types, and measurable specifications instead of vague claims.
