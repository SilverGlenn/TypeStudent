# Anti-Slop Documentation & Code Rules

Reject low-evidence, vague, or performative text across all documentation and comments:

- **No marketing fluff**: Write facts, technical details, and direct commands.
- **No repetitive introductory phrases**: Get straight to the point.
- **No banned AI vocabulary**: *delve, dive into, tapestry, seamless, groundbreaking, cutting-edge, empower, elevate, unleash, pivotal*.
- **No emoji spam**: Keep typography clean and readable.
- **Provide clear, runnable commands and concrete technical specifications**.
